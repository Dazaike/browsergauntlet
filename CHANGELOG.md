# Changelog

## [v1.0.0] - 2026-11-18

Initial release.

### Added
- 61 interactive challenges across 7 levels (basic, pointer, keyboard, advanced forms, dynamic website, complex scenarios, special interactions incl. iframe and shadow DOM).
- Practice, Challenge and Stress modes with deterministic seeds, retries, time limits, simulated latency and dynamic elements.
- Dashboard, results screen with category chart, activity log with filters, JSON report (`/report`, `window.browserGauntlet.getReport()`) and JSON/CSV export.
- Playwright demo suite covering representative challenges.
- Vercel SPA configuration (`vercel.json`).
